MoEngage introduced its Global Agent: one marketing agent orchestrating the whole stack

By inicIA · November 3, 2026 · 6 min read

Direct answer

At its NEXT Autumn'26 event, with an update posted October 30, 2026, MoEngage introduced the Merlin Global Agent: a universal agent for B2C marketing acting as a marketing teammate in a unified agentic workspace, with one orchestrator working across MoEngage and the rest of the customer's stack — warehouse, CRM, analytics and more — inheriting from day one the Context Hub, connectors, data and guardrails of the Merlin Agent Harness. The platform, used by more than 1,350 brands per the company, also adds Aampe's agentic decisioning, acquired in June 2026.

What the strengthened harness brings

  • A shared space for marketers and agents: the Merlin Agent Harness is the foundation built for enterprise marketing, with a workspace where people and agents collaborate on the same tools.
  • New analysis tools: agents now run behavior, funnel, retention, session and source analysis, and pull dashboard and chart data.
  • Expanded Context Hub and connectors: brand context, CRM and warehouse connectors and marketer-defined guardrails travel with every agent, instead of being configured tool by tool.
  • Creative generation inside the harness: the tools analyze funnels and draft channel-ready creative, inside the same governed environment.
  • Aampe decisioning built in: the decision about what each customer should see, from the Aampe acquisition, is now built into MoEngage.

What to pilot and what to ask before signing

  • One complete journey, not ten pilots: analyzing performance, creating a campaign, building a segment and preparing a report, in that order, is the test that shows whether the orchestrator works or just adds another tool.
  • Guardrails in writing: which data it can touch, which channels it can publish to and what spend it can move without approval. The marketer-defined guardrail is the promise; the written list is the proof.
  • Access for current customers: MoEngage says current customers should contact their account manager to start with these capabilities. Availability and plan are not detailed in the announcement.
  • Measure the full cycle: time from question to live campaign, with a log of every agent step. An orchestrator without a log is a black box with good marketing.
